# 03. 에러코드 정의서

모든 에러 응답은 다음 형식을 따른다 (참고: [02_API_명세서.md](02_API_명세서.md)).

```json
{
  "success": false,
  "data": null,
  "error": {
    "code": "POST_NOT_FOUND",
    "message": "게시글을 찾을 수 없습니다."
  }
}
```

## 공통 (COMMON)

| 코드 | HTTP 상태 | 메시지 | 설명 |
|---|---|---|---|
| COMMON_INVALID_INPUT | 400 | 요청 값이 올바르지 않습니다. | 필수 값 누락, 형식/길이 위반 등 유효성 검증 실패 |
| COMMON_METHOD_NOT_ALLOWED | 405 | 지원하지 않는 HTTP 메서드입니다. | 정의되지 않은 메서드로 호출 |
| COMMON_INTERNAL_ERROR | 500 | 서버 내부 오류가 발생했습니다. | 예상치 못한 서버 오류 |

## 인증 (AUTH)

| 코드 | HTTP 상태 | 메시지 | 설명 |
|---|---|---|---|
| AUTH_LOGIN_ID_DUPLICATED | 409 | 이미 사용 중인 아이디입니다. | 회원가입 시 `login_id` 중복 |
| AUTH_EMAIL_DUPLICATED | 409 | 이미 사용 중인 이메일입니다. | 회원가입 시 `email` 중복 |
| AUTH_INVALID_CREDENTIALS | 401 | 아이디 또는 비밀번호가 올바르지 않습니다. | 로그인 실패, 비밀번호 변경 시 현재 비밀번호 불일치 |
| AUTH_ACCOUNT_SUSPENDED | 403 | 이용이 정지된 계정입니다. | `status = SUSPENDED` 계정 로그인 시도 |
| AUTH_ACCOUNT_WITHDRAWN | 403 | 탈퇴한 계정입니다. | `status = WITHDRAWN` 계정 로그인 시도 |
| AUTH_UNAUTHORIZED | 401 | 로그인이 필요합니다. | Access Token 누락/무효 |
| AUTH_INVALID_TOKEN | 401 | 유효하지 않은 토큰입니다. | 토큰 서명 불일치, 형식 오류 |
| AUTH_TOKEN_EXPIRED | 401 | 토큰이 만료되었습니다. | Access/Refresh Token 만료 (`expires_at` 경과) |
| AUTH_TOKEN_REVOKED | 401 | 폐기된 토큰입니다. | 로그아웃 등으로 `revoked_at`이 설정된 Refresh Token 재사용 |

## 회원 (USER)

| 코드 | HTTP 상태 | 메시지 | 설명 |
|---|---|---|---|
| USER_NOT_FOUND | 404 | 회원을 찾을 수 없습니다. | 존재하지 않거나 탈퇴한 회원 조회 |

## 게시글 (POST)

| 코드 | HTTP 상태 | 메시지 | 설명 |
|---|---|---|---|
| POST_NOT_FOUND | 404 | 게시글을 찾을 수 없습니다. | 존재하지 않거나 삭제된 게시글 조회 |
| POST_FORBIDDEN | 403 | 게시글에 대한 권한이 없습니다. | 작성자 본인/관리자가 아닌 사용자의 수정·삭제 시도 |

## 댓글 (COMMENT)

| 코드 | HTTP 상태 | 메시지 | 설명 |
|---|---|---|---|
| COMMENT_NOT_FOUND | 404 | 댓글을 찾을 수 없습니다. | 존재하지 않거나 삭제된 댓글 조회 |
| COMMENT_FORBIDDEN | 403 | 댓글에 대한 권한이 없습니다. | 작성자 본인/관리자가 아닌 사용자의 수정·삭제 시도 |

## 파일 (FILE)

| 코드 | HTTP 상태 | 메시지 | 설명 |
|---|---|---|---|
| FILE_NOT_FOUND | 404 | 파일을 찾을 수 없습니다. | 존재하지 않거나 삭제된 파일 조회 |
| FILE_FORBIDDEN | 403 | 파일에 대한 권한이 없습니다. | 업로더 본인이 아닌 사용자의 삭제 시도 |
| FILE_TOO_LARGE | 413 | 파일 크기가 허용치를 초과했습니다. | 업로드 파일 용량 제한 초과 |
| FILE_UNSUPPORTED_TYPE | 415 | 지원하지 않는 파일 형식입니다. | 허용되지 않는 확장자/MIME 타입 업로드 |
